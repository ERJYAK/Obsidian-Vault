# Windows

Для начала необходимо проверить имеющуюся версию Redis. Для этого, открываем консоль, переходим в папку с Redis и выполняем `redis-cli INFO server`:
![[Pasted image 20250428152114.png]]

Если параметр "redis_version" < 6.0, то сам Redis не поддерживает TLS/SSL соединения.

## Настройка Legacy Redis

### Установка stunnel

Так как сам Redis в таком случае не поддерживает TLS/SSL, то для этого нам необходимо буде установить специальное прокси - `stunnel`. 
Запускаем установщик, выбираем опцию "Установить для всех пользователей":
![[Pasted image 20250428152810.png]]
Везде ставим "галки":
![[Pasted image 20250428152840.png]]
Оставляем стандартный путь для сохранения:
![[Pasted image 20250428152912.png]]
Затем установщик попросит ввести данные для генерации сертификата:
1. **Country Name (2 letter code)**  
     -  Двухбуквенный код страны по стандарту ISO-3166, в которой юридически зарегистрирована ваша организация или находится сервер.  
     -  Пример: `RU` (Россия).
    
2. **State or Province Name (full name)**  
    - Полное название региона или области (не сокращайте).  
    - Пример: `Moscow`, `Moscow Oblast`.
    
3. **Locality Name (eg, city)**  
    - Название города или населённого пункта, где расположен сервер.  
    - Пример: `Moscow`.
    
4. **Organization Name (eg, company)**  
    -  Полное юридическое наименование вашей организации.  
    - Поле **опционально** — можно просто пропустить и нажать Enter
    
5. **Organizational Unit Name (eg, section)**  
    - Отдел или подразделение в организации (например, `Indusoft`).  
    - Поле **опционально** — можно просто пропустить и нажать Enter.
    
6. **Common Name (e.g. server FQDN or YOUR name)**  
    - Очень важно: здесь нужно указать **точное имя**, по которому клиенты будут подключаться к вашему Redis-серверу через `stunnel`.
    - Если вы используете доменное имя — `redis.example.com`.
    - Если прямо по IP — укажите IP (`192.168.1.100`).  
        – При проверке сертификата клиент сверяет это поле с тем, что указано в запросе на подключение.
![[Pasted image 20250428154216.png]]
Нажимаем "Next" и не выбираем запуск после инсталяции, а просто нажимаем "Finish":

### Настройка openssl

Для генерации сертификата необходимо повторно настроить файл конфигурации `openssl.cnf`. Он находиться в папке `config` по пути, который блы указан при установке. При открытии файл будет представлен в стандартном формате для конфигурации. В этом файле "разделы" описываются как `[ имя раздела ]`. Оставляем стандартыне настройки всех разделов кроме `[ stunnel_dn ]` и  `[ stunnel_extensions ]` , а так же добавить раздел `[alt_names]`, в котором указываются IP сервера и DNS имя сервера. Раздел `[ req ]` необходимо дополнить строкой `prompt							= no`:
![[Pasted image 20250428164553.png]]
Сохраняем изменения.

### Конфигурация Redis
Перед тем как изменять конфигурационный файл Redis необходимо его остановить в службах. Затем переходим в папку с Redis и находим файл `redis.windows-service.conf`. 

Далее добавляем строку `bind 127.0.0.1`. IP адресс обязательно должен быть локальным, именно таким образом блокируется доступ извне к Redis.

Опционально можно добавить пароль: необходимо в этом же файле добавить `requirepass пароль`

Сохраянем файл конфигурации. 
Открываем консоль, переходим в папку с Redis. 

Для проверки того, что Redis слушает только локально вызываем коману `netstat -ano | findstr ":6379"`.  Redis должен слушать только по указанному локальному IP и port:


Для проверки пароля вызываем команду `redis-cli -h локальный IP -p порт -a "пароль" ping`. При верно указанном пароле консоль должна вывести "PONG", в ином случае "(error) NOAUTH Authentication required.":
![[Pasted image 20250428163001.png]]
### Сертификат
После того, как мы настроили и проверили Redis и openssl необходимо сгенерировать сертификат. Этот сертификат будет использоваться для безопасного доступа к Redis. Для этого открываем консоль и переходим по пути установки stunnel, а далее переходим в папку `bin`. Затме вызываем команду:
```bash
openssl req -new -x509 -config "путь до файла\openssl.cnf" -nodes -days 3650 -keyout "Путь куда хоти сохранить ключ\stunnel.key" -out "Путь куда хоти сохранить сертификат\stunnel.crt"
```
![[Pasted image 20250428170100.png]]
Затем нужно убедиться, что в сертификате присутсвует IP сервера, который мы указывали ранее. Для этого в powershell необходимо перейти по пути установки stunnel, а далее переходим в папку `bin` и выполняем команду:
```powershell
.\openssl.exe x509 -in "путь до сертификата\stunnel.crt" -noout -text |
>>   Select-String "Subject Alternative Name" -Context 0,1
```
В ответе должны получить указанный IP:
![[Pasted image 20250428170404.png]]

После проверки сертификата его необходимо добавить в доверенные. Для этого копируем сертификат на компьютер с программой, которая подключается к Redis. Затем открываем терминал от имени Администратора и выполняем:
```bash
certutil -addstore Root "путь до сертификата\stunnel.crt"
```  
Получаем сообщени о том, что сертификат успешно добавлен:
![[Pasted image 20250428180002.png]]
### Настройка stunnel
Для корректной работы прокси необходимо правльно настроить файл `stunnel.conf`. Он находиться в папке `config` по пути, который блы указан при установке. При открытии файл будет представлен в стандартном формате для конфигурации. Его необходимо полностью очистить и заполнить таким образом:
```bash
; ----------- глобально -----------
output     = stunnel.log ; Путь к лог файлу
cert       = stunnel.crt ; Путь к сертификату
key 	   = stunnel.key ; Путь к ключу
sslVersion = TLSv1.2 ; Версия SSL
socket     = l:TCP_NODELAY=1
socket     = r:TCP_NODELAY=1

; ----------- Redis-служба -----------
[redis-tls]
accept  = 0.0.0.0:6380 ; Предпочтительно выбрать порт 6380 - к нему будут подключаться программы         
connect = 127.0.0.1:6379 ; Указываем IP, который указали ранее при настройке     "bind" и порт.         
```
Сохраняем изменения.

Открываем терминал, переходим по пути установки stunnel, а далее переходим в папку `bin` и выполняем команду:
```bash
stunnel.exe -install "Путь к файлу конфигурации\stunnel.conf"
```
И получаем сообщение об успешной установке службы.

Запускаем службу. Находим по указанному ранее путь лог файл и открываем его. Там должно быть сообщение об успешном запуске службы:
![[Pasted image 20250428172551.png]]

В том же терминале вводим команду:
```bash
netstat -ano | findstr ":указзаный порт"
```
Получаем сообщение о том, что порт слушается:
![[Pasted image 20250428172738.png]]

Далее выполняем:
```bash
openssl s_client -connect IP:6380 -servername IP -CAfile "путь до сертификата\stunnel.crt"
```
В конце длинного вывода должны получить сообщение о нулевом коде возврата:
![[Pasted image 20250428180215.png]]
